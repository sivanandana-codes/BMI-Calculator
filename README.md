
# BMI Calculator

A simple BMI Calculator application that allows users to calculate their Body Mass Index based on their height and weight.

# Features
- User input for personal details
- BMI calculation
- Displays BMI result
- Simple and user-friendly interface

# Technologies Used
- Python
- FastAPI
- HTML
- CSS
- JavaScript

## Project Structure
- index.html – Main input page
- Result.html – Displays BMI result
- main.py – Python backend
- script.js – JavaScript functionality
- style.css – Styling

# How to Run
1. Clone this repository.
2. Install the required Python packages.
3. Run the FastAPI application using Uvicorn.
4. Open the application in your browser.
